# Data Directory

This directory stores the synthetic dataset generated by this project's deterministic pipeline.

## Structure

- `exports/csv/`: Exported CSV files for all 10 database entities plus telemetry sample and anomaly records.
- `exports/json/`: Corresponding JSON exports for all entities.
- `exports/sql/`: SQL seed files (`seed_master_and_events.sql`, `seed_anomalies.sql`) for deterministic database setup.
- `ground_truth/`: Sequestered ground-truth records isolated from the feature pipeline:
  - `ground_truth.csv` / `ground_truth.json`: 50 labelled deliberate anomaly records (5 categories × 10 rows).
  - `failures_ground_truth.csv` / `failures_ground_truth.json`: 150 failure event records used for offline evaluation.
- `raw/`: Reserved for raw ingest sources. Currently empty (`.gitkeep`).
- `processed/`: Reserved for pre-processed intermediate datasets. Currently empty (`.gitkeep`).

## Telemetry Export Note

`exports/csv/telemetry_sample.csv` contains a **5,000-row sample** for inspection and reproducibility verification.
The full 2,160,000-row telemetry dataset resides in the PostgreSQL database and is not exported to CSV due to file size.
